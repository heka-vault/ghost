# Glossary

The words Ghost uses, one meaning each. The operator hires an **agent** and talks to it;
what is said is the **conversation**. The phone metaphor of the first increment (*line*,
*patch me through*) is gone (ADR 0024), and so are departments (ADR 0035).

| Term | Meaning | Not |
|---|---|---|
| **Agent** | What the operator hires, talks to and retires: its own name, job, persona, voice, private memory, notes and transcript, in `~/.config/ghost/agents/<slug>/`. Ghost is agent zero. The desktop's Agents screen and the phone's Home list them. The code and the control API call the same object a *conversation* (`ghost_core::conversations`, `/conversations`); the word to show is **agent**. | A session. |
| **Conversation** | What is said with an agent: its transcript, with the agent's memory of it. Opening an agent in the desktop shows the conversation first; the agent's settings sit behind it. In code, also the storage name for the agent. | |
| **Session** | One stretch with the mic open, from a wake or a call to a hang-up. A session starts in one agent (Ghost at the desk; on the phone, Ghost or the agent you called) and can be transferred to another. | |
| **Call** | A phone session, started from the phone's Home: the ghost for Ghost, a key for an agent. | |
| **Transfer / switch** | Moving a running session to another agent; "back to Ghost" returns. Retired agents are out of reach by voice. | |
| **Hire / retire / rehire** | Create an agent; take it out of voice routing and the active list, transcript and audit kept; bring it back. Delete removes it for good. | |
| **Rule** | A line of Ghost's `AGENTS.md`, in every agent's prompt. "Add a rule" appends the operator's words verbatim through the gate. | A persona, which is one agent's. |
| **Checked out (hold)** | "Hang on, Ghost": the session stays, Ghost stops listening until addressed by name at the start of an utterance; nothing heard meanwhile is kept (ADR 0021). | Hung up. |
| **Hang up** | A goodbye ends the session; Ghost says a short goodbye and the desk returns to passive (ADR 0021). The End button on the phone ends it silently. | "Go to sleep" (gone). |
| **Passive** | The desk listening locally for the wake phrase only; nothing leaves the machine (ADR 0010). | |
| **Gate** | The one path for every change: the permissions' level, bounds, the yes when it asks, the call, the audit (ADR 0007, 0011, 0034). | |
| **Skill** | A `SKILL.md` folder: instructions the model reads on demand through `read_skill`, never a source of permission. Ghost's own `skills/`, then the operator's `~/.agents/skills`. Scripts in it run only through the scripts app, a change through the gate (ADR 0023). | |
| **App** | Something connected to Ghost (GitHub, Linear, Notion): signed in to, given a key, or run on this computer; listed in `apps.json` and reached by every agent (ADR 0034). Every tool it has is offered: a read-only one is a read, anything else a change through the gate. Also *source*: an app, the agents, the rules or the outputs, as the gate and the audit know them (the audit's `source` field). | A *server* or an *MCP server*: the protocol's words, never shown. An *ability* (ADR 0012, superseded). |
| **Ghost's own app** | Ghost as one of its own apps, named `ghost`: everything Ghost can do, as tools every agent has (`ghost_docs_search`, `ghost_notify`, `ghost_recall`, `ghost_watch_manage`, …; [docs/tools.md](docs/tools.md)). Served inside the daemon, never connected and never in `apps.json`; its reads are reads, its changes go through the gate, and `ghost.*` permissions cover it (ADR 0045, ADR 0052). A core of its tools is in every turn; the rest are found with `ghost_tools_search`. The same app is what an outside tool reaches, narrower (ADR 0048). | A connected app: nothing to sign in to, nothing leaves the machine. The control API, which a model never reaches. |
| **Outside tool** | Another tool on this computer that the operator let use Ghost: Claude Code, Cursor, Codex. It reaches Ghost's own app through a listener of its own, with a name and a token shown once (Settings › Outside tools, `ghostd mcp add`), and can tell the operator something ("From Claude Code: the build finished"), read Ghost's status and documentation, and wait for an acknowledgment. Its reads are reads and its changes go through the gate under the session `client:<name>` (ADR 0048). The code and the control API call it a *client* (`ghost_core::ghost_app::clients`, `/clients`); the word to show is **outside tool**. | An app, which Ghost connects to; an outside tool connects to Ghost. An agent, which lives in Ghost. |
| **Connect / disconnect** | Add an app to Ghost from the catalog, by its address, or by pasting another tool's config; take it away again (its sign-in and the keys Ghost kept for it go too). | |
| **Sign in** | Connecting an app the way a site offers "Sign in with Google": Ghost opens the browser and keeps what comes back. When the app wants it again, it waits on the waiting list. | Typing a key, which is *use a password*. |
| **Password** | Anything secret Ghost holds for the operator: an API key, a token, an account password. Kept in Ghost's own vault, encrypted, referred to by name (`${GITHUB_TOKEN}`) and filled in only where it is used: an app's environment, a request header, the model connection. A password goes in and never comes back out: not to the desktop, the control API, a log, the audit, a transcript or the model, and an app that echoes one gets it replaced before anything reads the result. The vault is one encrypted file, its key in the operator's keyring (ADR 0036); the old plain files (`~/.config/ghost/env`, `apps.env`) and heka-vault are imported once; Ghost then deletes the plain files (keeping them if a value couldn't be imported, or one differs from the vault's copy), and heka-vault's own config (`~/.config/heka-vault/ghost.env`) is left for the operator to delete. | A *secret*, *key*, *API key* or *token*: the engineering words, kept in code, never shown. An `.env` file. |
| **Catalog** | The apps Ghost can connect, from its own copy of the public app registry, first-party ones first. Its text is shown to the operator, never to the model. | |
| **Permission** | A rule in `[permissions]` of `policy.toml`: an app, a tool, or a tool with argument patterns, in one of `block`, `ask`, `quiet` or `allow`. The most careful match wins; what no rule names runs at the *mode* (`open`, `ask`, `read-only`). There is one set; nothing narrows it per agent (ADR 0035). | A *level* (`deny`, `confirm`, `announce`, `quiet`), the gate's own word for what a permission resolves to. |
| **Watch** | What the operator declares in `watches.json` (or `hooks.json`) to observe an outside system: a read polled on an interval, or a signed request pushed to the daemon. It keeps typed fields and decides deterministically first, then with Jev, then a model, only where it declares them (ADR 0028). An agent may make a polled one with the operator's yes (`ghost_watch_manage`, ADR 0052), marked as its own; a webhook is the operator's alone. | A schedule, which runs an agent at a time. |
| **Observation** | What one look by a watch found: its typed fields, nothing else. Untrusted data. | |
| **Item** | Something a watch, Ghost itself, an agent or an outside tool is tracking, with a stable key, so one failure is one item however often it is seen. Resolved when its source says so; an agent's (`ghost_notify`) or an outside tool's (`notify`) when the one that put it there clears it. | An agent's *notes*, which are its own `notes.md`. |
| **Response** | What a watch does with its items: *record*, *tell* (put it on the waiting list) or *act* (an agent looks into each new one in a run, on an instruction the operator wrote; ADR 0029, ADR 0047). The operator's, never the model's. | A *rule*, which is a line of `AGENTS.md`. |
| **Schedule** | Something an agent does on its own, at a time: an agent, an instruction, and when (once *at* a time, *every* interval, or a *cron* expression in a time zone). The operator adds one on the Watching screen; an agent told to ("check the build every morning at nine") sets up its own, through the gate. Kept in Ghost's database, not in its folder (ADR 0047). | A *watch*, which looks without a model and is declared in `watches.json`. A *routine*, a *job* or a *cron job*: one word, schedule. |
| **Recall** | An agent finding what was said before in its own stored turns (`ghost_recall`), by words, not by meaning: a full-text index over the transcript, kept in step as turns are added and pruned (ADR 0041). Ghost searches any agent's. Nothing Ghost heard while waiting for its name is ever there. | Memory, the agent's rolling summary and notes. |
| **Run** | One execution of a schedule, or of a watch's *act*: the agent working with nobody there, in writing, with the same tools through the same gate and no audio. Its answer goes to the waiting list and into the agent's transcript; `[SILENT]` says nothing; a change that needs a yes waits on the waiting list (ADR 0047). | A *session*, which has the microphone open and the operator in it. |
| **Check** | A schedule's look before its run: one of a connected app's read-only tools, called with no model. The agent runs only when what it returned has changed (ADR 0047). | A watch's *check*, the deterministic test over its fields; the idea is the same. |
| **Waiting list** | The items that need the operator: what watches *tell*, what an agent or an outside tool has to tell them, what a scheduled run answered, questions, changes waiting for a yes, apps that aren't connected or want a new sign-in, files in Ghost's folder with a problem. "What needs me?" reads it (ADR 0029). | The audit, which is history. |
| **Question** | An item with an answer: something an agent, a run, an outside tool or a connected app asks the operator, with up to four choices, an expiry, and who asked. It is on the waiting list and reaches the operator by the routes like any item; answering it is its acknowledgment and its resolution. A change waiting for a yes is shown as the question Yes or No (ADR 0051). | An agent asking aloud in a session, which is just conversation. A *clarify* or an *ask_user*: one word, question. |
| **Answer** | What the operator says to a question, recorded as they gave it with where it came from: a click or their typed words in the desktop (`desktop`), a signed request from their paired phone (`phone`), or their own words in a session (`voice`), checked against what they just said. A model never supplies one; a choice is matched by fixed rules. A question asked from a run is followed up: its answer starts one more run of the same agent (ADR 0051). | A *yes* to a change, which is the gate's and is judged as ever. |
| **Ring** | The desk ringing the operator's phone for an item at `call` urgency: a full-screen incoming call over the live stream. Answered, it opens an ordinary call with the agent that asked, which opens with the question; declined is "not now"; unanswered after 30 seconds goes to the next route (ADR 0051, issue #22). | A *call*, which is a phone session, whoever started it. |
| **Route** | How Ghost reaches the operator about an item: the digest, desk voice, a desktop notification, the phone app, a ring, a carrier, ntfy. Which ones, and how loud, is the operator's policy (ADR 0031, ADR 0051). | |
| **Delivered / acknowledged** | Delivered: a route passed the item on. Acknowledged: the operator heard it (replied, opened it, pressed acknowledge). Only acknowledged stops the alerting; a snooze stops it until a time. | |
| **Not listening** | Ghost's microphone is closed, by the operator's switch: no capture is open, so nothing is heard, not even its name. Typing, the phone's own call, schedules, watches and questions go on. Turned off from the desktop, the tray, the phone, a shortcut or by saying "Ghost, stop listening"; turned back on only by the operator's hand (ADR 0057). The code says `listening` and `not_listening`. | *Quiet* (do-not-disturb), which stops Ghost reaching out but not hearing. *Hold*, which keeps a session and waits for its name. *Muted*, the phone call's own mic button. |
| **Output** | A file Ghost made, in `~/.config/ghost/out/`, written through the gate (ADR 0033). Ghost never runs it. | |
| **Wisp** | Ghost's mascot. Ghost is always Wisp; each agent is one of Wisp's family (a drop, a bell, a hood, a cloud, a lantern, a star, a moth, or Wisp itself) in a colour of its own: its **look**, a field on the agent the operator picks (ADR 0061). | |

Retired words, so old notes still read: a **line** was an agent; a **toolkit** was a
permission bundle in the policy file and a **template** a folder that stamped one out; a
**department** was a folder of rules, skills, memory and agents, with its own permissions,
and a **move** put an agent in another one (ADR 0024, gone with ADR 0035, as are its
**journal** and shared memory); a **settled** line is a retired agent; a thread's
**scope**, an **allowlist** and **owner** routing are gone (ADR 0034); a **server** is an
app, and its **declaration** of reads, writes and levels is gone.
