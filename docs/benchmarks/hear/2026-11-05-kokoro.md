# How Ghost hears: the first run, Kokoro's takes in three voices (2026-11-05)

`ghostd perf hear --voices am_michael,af_heart,bm_george` at the commit below, before any
change to the speech-in path: the baseline for the rendered takes. Compare a later run
with `--baseline docs/benchmarks/hear/2026-11-05-kokoro.results.json`. The method is
[../hear-harness.md](../hear-harness.md).

**What it says.** Even on clean synthetic speech the VAD splits 57 of 111 spoken takes,
and reading each piece alone costs words: reading the turn whole takes the word error rate
from 7.2% to 4.2%, better beyond noise (−5.7 to −0.6 points), for 0.05 s more at the
close's p95. Two things the turn read does not fix: a short reply cut as its own segment
can read as nothing ("Not yet."), where the whole file reads it; and the whole file read
with no VAD makes words up from room noise in 2 of 30 silent takes, which the VAD's gate
prevents. The operator's own takes (`make record-hear`) are the test that counts.
